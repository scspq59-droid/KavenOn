# KavenOn

KavenOn to niewielka aplikacja internetowa do organizowania codziennych zadań. Projekt został przygotowany w ramach przedmiotu **Zarządzanie projektem wdrożeniowym**.

## Funkcjonalności

- Dodawanie, edytowanie i usuwanie zadań.
- Oznaczanie zadań jako ukończone lub aktywne.
- Ustawianie priorytetu: niski, średni lub wysoki.
- Ustawianie terminu wykonania i oznaczanie zadań przeterminowanych.
- Wyszukiwanie oraz filtrowanie zadań.
- Sortowanie według daty dodania, terminu i priorytetu.
- Statystyki zadań i pasek postępu.
- Zapisywanie danych w przeglądarce za pomocą LocalStorage.

## Wykorzystane technologie

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API

## Uruchomienie

1. Pobierz repozytorium lub sklonuj je na komputer.
2. Otwórz folder projektu w Visual Studio Code.
3. Otwórz plik `index.html` w przeglądarce. Możesz też użyć rozszerzenia **Live Server** w VS Code.

Aplikacja nie wymaga instalacji serwera ani dodatkowych zależności.

## Przechowywanie danych

Zadania są zapisywane lokalnie w przeglądarce użytkownika. Wyczyszczenie danych witryny lub użycie innej przeglądarki może usunąć albo ukryć zapisane zadania.
